3. Never let a real decision sit only in chat — if it isn't here or in a permanent doc by the end of the session, it hasn't been captured (see `CLAUDE.md`'s Knowledge Capture Policy).

Founder formalized the governing philosophy of the HURKL Trusted Business Network (HTBN) — a deep expansion of the "HURKL Trusted Trade Network" concept from Session 006 (original), same file (`TRUSTED_TRADE_NETWORK.md`), not a new duplicate file:

- **Founding mission** — HURKL's objective is to become the *most trusted* network, explicitly not the *largest*. Every HTBN decision protects that mission.
- **Network philosophy** — HTBN membership is a privilege, separate from using Mason; it represents demonstrated professionalism, reliability, safety, integrity, and continuous improvement, not mere software usage.
- **Business stewardship** — HURKL protects customers, member businesses, employees, its own reputation, and the network's long-term value; protecting the network outweighs avoiding uncomfortable conversations.
- **Mason's role, tightly bounded** — Mason never judges people, never labels businesses, never removes members. It only gathers objective operational evidence (licensing, insurance, certifications, equipment maintenance, safety compliance, documented regulatory actions, verified customer feedback, project completion history, documentation quality, responsiveness, operational organization) and may privately recommend an internal stewardship review. **Only HURKL administrators decide membership** — recorded as an explicit new Tier 3 ("never autonomous") item in `SECURITY.md` §4.
